# HoloDesk 

A gesture-controlled AI desktop agent — like Iron Man's interface, built step by step.

## What is this?

HoloDesk is a multimodal AI assistant that you can:
- **Control with hand gestures** (grab, move, swipe)
- **Talk to naturally** (voice commands)
- **Use to manipulate on-screen objects** (cards, notes, data)

## Current Progress

- [x] **Step 0:** Window + Webcam + FPS display
- [ ] Step 1: Hand tracking → cursor dot
- [ ] Step 2: Pinch gesture → grab/drag objects
- [ ] Step 3: Voice commands
- [ ] Step 4: AI Agent with tools
- [ ] Step 5: Database + Cloud storage

## Tech Stack

- Python
- Pygame (UI/graphics)
- OpenCV (webcam)
- MediaPipe (hand tracking - coming next)
